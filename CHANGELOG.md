# Changelog

Notable project changes are recorded here. This project follows semantic versioning where practical.

## Unreleased

- Add independently reviewed multilingual evaluation data.
- Add versioned legal-data review records.

## 4.0.0 — 2026-08-25

### Added

- Date-aware selection between current BNS and legacy IPC context.
- Structured coverage for 23 BNS-linked categories and selected special laws.
- Strong, moderate and preliminary match-strength labels.
- Supporting signal words and alternative category suggestions.
- Multilingual next steps, evidence guidance and official assistance resources.
- Copyable summaries, print-to-PDF support and clearer privacy notices.
- Responsive redesigned interface and legal-technology artwork.
- Thirteen automated classifier and API tests.

### Changed

- Reframed the product as a preliminary legal-awareness assistant rather than a crime verdict system.
- Separated machine-learning classification from maintained legal reference data.
- Improved accessibility, mobile layout and responsible-AI explanations.

## 3.0.1 — 2026-08-24

### Fixed

- Prevented a single voice utterance from being appended multiple times.

### Added

- Updated BNS context, richer consequences and additional user guidance.

## 2.0.0 — 2026-08-23

### Added

- FastAPI application and JSON analysis endpoint.
- English, Hindi and Telugu text and voice input.
- TF-IDF and Logistic Regression incident classification.
- Render deployment configuration.

## 1.0.0

- Initial IPC keyword-matching academic prototype.
